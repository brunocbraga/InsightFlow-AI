\# 🚀 InsightFlow AI



> Transformando dados em decisões inteligentes através de Business Intelligence, Engenharia de Dados e Inteligência Artificial.



\---



\## 📖 Sobre o Projeto



O \*\*InsightFlow AI\*\* é um projeto completo que simula a implementação de uma plataforma moderna de Business Intelligence para uma empresa fictícia de e-commerce.



O objetivo é demonstrar todas as etapas de um projeto profissional de dados, desde a coleta e modelagem das informações até a geração automática de insights utilizando Inteligência Artificial.



Diferentemente de um dashboard tradicional, este projeto aborda todo o ciclo de vida dos dados.



\---



\## 🎯 Objetivos



\- Construir uma arquitetura moderna de dados.

\- Criar um banco de dados relacional utilizando PostgreSQL.

\- Desenvolver processos de ETL.

\- Construir um Data Warehouse utilizando Star Schema.

\- Desenvolver dashboards executivos no Power BI.

\- Integrar Inteligência Artificial para geração automática de insights.

\- Automatizar todo o fluxo utilizando n8n.
