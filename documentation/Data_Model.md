# Data Model

## Objetivo

Este documento descreve a estrutura lógica do banco de dados da Insight Commerce.

O objetivo é armazenar informações de clientes, produtos, pedidos, pagamentos, entregas, vendedores e canais de venda de forma normalizada, permitindo análises estratégicas e alimentando o Data Warehouse utilizado pelo Power BI.

---

# Entidades

- Clientes
- Produtos
- Categorias
- Pedidos
- ItensPedido
- Vendedores
- Canais
- Pagamentos
- Entregas
